## Overview

EASYCRED categorizes loan products into two distinct operational flows: **Real-Time API Products** and **Offline Products**.

Your partner account is granted access to specific products during onboarding. When product permissions are updated in the EASYCRED Partner Portal, changes take effect immediately across all active API keys.

---

## 1. Real-Time Products (Digital API Journeys)

These products run end-to-end digitally through the EASYCRED Partner API. You can initiate them in **Headless (`API_HEADLESS`)** or **Hosted (`API_HOSTED`)** mode.

## 2. Offline Products (EASYCRED Desk Operations)

Offline products cater to higher ticket sizes, specialized collateral, or complex underwriting requirements. These are submitted as leads via the EASYCRED Partner Portal and assigned directly to dedicated credit desks.

| Product | Workflow | Operation Mode |
| :--- | :--- | :--- |
| **Home Loan** | Managed by EASYCRED Home Lending Desk | Lead capture $\rightarrow$ Offline field verification & legal scrutiny |
| **Loan Against Property (LAP)** | Managed by Mortgage Operations | Physical property valuation & documentation |
| **Car / Vehicle Loan** | Managed by Auto Lending Desk | Dealership / vehicle asset financing |
| **Education Loan** | Managed by Education Lending Desk | University admission & co-borrower assessment |
| **Working Capital** | Managed by Commercial B2B Desk | Balance sheet appraisal & credit line setup |

<Note>
  Offline products are managed through the Partner Portal interface. Attempting to initiate an offline product code through the digital journey API returns `403 Forbidden`.
</Note>

## Dynamic Access Control

Check the active products permitted on your API key at any time:

```http
GET /api/v1/partner/products
```

If an application is initiated for a product code outside your configured permissions, the gateway responds with:

```json
{
  "success": false,
  "error": "Product not enabled for this API client"
}
```

To enable additional real-time or offline products, request access directly from your EASYCRED account manager or through the Partner Portal settings.
