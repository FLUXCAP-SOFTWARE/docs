## Overview

These endpoints work at any time, independently of an active journey session. Use them to monitor the status of applications, fetch lead metadata, and receive real-time webhook events.

---

## List Enabled Products

Inspect which loan products are currently enabled for your API key:

```http
GET /api/v1/partner/products
```

**Required Scope:** `products:read`

```json
{
  "success": true,
  "data": {
    "products": [
      {
        "code": "ONLINE_PERSONAL",
        "displayName": "Personal Loan",
        "category": "PERSONAL"
      },
      {
        "code": "ONLINE_GOLD",
        "displayName": "Gold Loan",
        "category": "GOLD"
      },
      {
        "code": "ONLINE_SHORT_TERM",
        "displayName": "Pocket Loan",
        "category": "PERSONAL"
      },
      {
        "code": "ONLINE_BUSINESS",
        "displayName": "Business Loan",
        "category": "BUSINESS"
      }
    ]
  }
}
```

## Get Application Status

Retrieve the current processing or terminal status of an application by its `applicationId`:

```http
GET /api/v1/partner/leads/{applicationId}/status
```

**Required Scope:** `leads:status:read`  
*Requires only standard HMAC headers — no `X-Journey-Session` token needed. Compatible with both hosted and headless applications.*

```json
{
  "success": true,
  "data": {
    "applicationId": "app_6aa8fe47fdcd2d2407fbcee6",
    "status": "COMPLETED"
  }
}
```

## List Partner Leads

Retrieve a paginated list of applications originated by your account. Returns operational metadata without exposing raw customer PII:

```http
GET /api/v1/partner/leads?page=1&limit=20
```

**Required Scope:** `leads:read`

| Query Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | integer | `1` | Page index (1-based) |
| `limit` | integer | `20` | Results per page (up to `100`) |

## Webhooks vs. Polling

EASYCRED supports asynchronous webhook delivery for status transitions:

- **Webhooks:** Instant push notifications on state changes (`SANCTIONED`, `REJECTED`, etc.). Ideal for hosted integrations.
- **Status Polling:** On-demand check for headless polling or fallback reconciliation.

See the [Webhooks Guide](/webhooks) to configure endpoints and signature verification.

## Terminal Status Reference

| Status | Description |
| :--- | :--- |
| `COMPLETED` | Loan successfully sanctioned and disbursed. |
| `REJECTED` | Application did not meet credit criteria. |
| `NO_OFFERS_AVAILABLE` | No offers returned for the applicant's profile. |
| `OFFLINE_PROCESSING` | Assigned to an EASYCRED credit officer for physical follow-up. |
| `ABANDONED` | Borrower timed out before completing verification. |
| `EXPIRED` | Application exceeded the 72-hour journey TTL. |
