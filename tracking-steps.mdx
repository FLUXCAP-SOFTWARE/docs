## Overview

EASYCRED provides flexible tracking mechanisms to monitor loan progress in real-time across both **Hosted (`API_HOSTED`)** and **Headless (`API_HEADLESS`)** journeys:

| Tracking Method | Integration Mode | Endpoint / Mechanism | Required Headers | Description |
| :--- | :--- | :--- | :--- | :--- |
| **Check Journey Status** | Hosted & Headless | `GET /api/v1/partner/journey/{journeyId}` | Standard HMAC headers | Real-time journey state machine lookup. Returns current step, offers, and terminal outcome. |
| **List Applications** | Hosted & Headless | `GET /api/v1/partner/leads` | Standard HMAC headers | Paginated audit list of all applications originated by your account with real-time status. |
| **Application Status** | Hosted & Headless | `GET /api/v1/partner/leads/{applicationId}/status` | Standard HMAC headers | Direct status lookup using the 24-character hex `applicationId`. |
| **Webhooks** | Hosted & Headless | HTTP POST to your server | `x-webhook-signature`, `x-webhook-timestamp`, `x-webhook-nonce` | Real-time push events (`journey.updated`, `journey.completed`, `journey.rejected`, `journey.failed`). |

---

## Tracking ID Architecture

Understanding EASYCRED's tracking IDs ensures seamless reconciliation:

- **`journeyId` (`jrn_<uuid>`):** Returned by `POST /journey/initiate` for both Hosted and Headless channels. It is the primary identifier used for **Journey Status polling** (`GET /journey/{journeyId}`) and **Webhook notifications** (`data.journeyId`).
- **`applicationId` (24-character hex MongoDB ObjectId):** Generated when the loan application is recorded in EASYCRED's database (e.g. `6ae1b47ce5656d0175f6596a`). Returned in `GET /api/v1/partner/leads` and queried via `GET /api/v1/partner/leads/{applicationId}/status`.
- **Internal Reference IDs:** Internal banking rail or lender session IDs (such as 36-character UUID strings like `01a18...`) are managed privately by EASYCRED's infrastructure. API partners do not use these IDs; you always track externally using `journeyId` or `applicationId`.

## 1. Check Journey Status (`GET /journey/{journeyId}`)

Check the real-time state, lender offers, and outcome of a journey using its `journeyId`:

```http
GET /api/v1/partner/journey/{journeyId}
```

**Required Scope:** `leads:status:read`  
**Headers:** Standard HMAC headers (`x-api-key`, `x-timestamp`, `x-nonce`, `x-signature`)  
*(Works for both Hosted and Headless modes. No `X-Journey-Session` token is required).*

### Response Example

```json
{
  "success": true,
  "data": {
    "journeyId": "jrn_d6a05d54-ae16-4dfb-9590-fa7baa332267",
    "productCode": "ONLINE_PERSONAL",
    "channel": "API_HOSTED",
    "currentNextAction": {
      "type": "NO_OFFERS_AVAILABLE",
      "category": "TERMINAL",
      "pollIntervalSeconds": null,
      "url": null,
      "endpoint": null
    },
    "offers": [],
    "outcome": "NO_OFFERS_AVAILABLE",
    "startedAt": "2026-10-28T08:38:20.450Z"
  }
}
```

## 2. List Partner Leads & Applications

Retrieve a paginated list of all applications originated by your account. This endpoint returns real-time operational status without exposing customer PII:

```http
GET /api/v1/partner/leads?page=1&limit=20
```

**Required Scope:** `leads:read`  
**Headers:** Standard HMAC headers (`x-api-key`, `x-timestamp`, `x-nonce`, `x-signature`)

### Query Parameters

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `page` | integer | `1` | Page index (1-based). |
| `limit` | integer | `20` | Results per page (maximum `100`). |

### Response Example

```json
{
  "success": true,
  "data": {
    "leads": [
      {
        "applicationId": "6ae1b47ce5656d0175f6596a",
        "loanType": "PERSONAL_LOAN",
        "loanAmount": 150000,
        "status": "POLL_FOR_OFFERS",
        "submittedAt": "2026-10-28T08:38:20.450Z"
      },
      {
        "applicationId": "6ae1aa0ee5656d0175f656f5",
        "loanType": "PERSONAL_LOAN",
        "loanAmount": 200000,
        "status": "NO_OFFERS_AVAILABLE",
        "submittedAt": "2026-10-28T07:53:50.842Z"
      }
    ],
    "total": 33,
    "page": 1,
    "limit": 20
  }
}
```

## 3. Get Application Status by `applicationId`

Retrieve the current processing or terminal status of an individual application:

```http
GET /api/v1/partner/leads/{applicationId}/status
```

**Required Scope:** `leads:status:read`  
**Headers:** Standard HMAC headers  

### Response Example

```json
{
  "success": true,
  "data": {
    "applicationId": "6ae1aa0ee5656d0175f656f5",
    "status": "NO_OFFERS_AVAILABLE"
  }
}
```

## Complete Status Reference

EASYCRED returns standardized status codes across the Leads API, Journey API, and Webhooks:

### Terminal Outcomes (`data.outcome` / Terminal `status`)

When an application completes its lifecycle, it transitions into one of these terminal outcomes:

| Status Code | Meaning | Description |
| :--- | :--- | :--- |
| `COMPLETED` | Loan Sanctioned & Disbursed | Loan funds have been successfully transferred to the borrower's verified bank account. |
| `REJECTED` | Application Declined | Application did not meet lender credit underwriting criteria. |
| `NO_OFFERS_AVAILABLE` | No Matching Offers | Credit profile evaluated, but no partner lenders returned viable credit offers for this applicant. |
| `OFFLINE_PROCESSING` | Manual Officer Review | Application routed to an EASYCRED credit officer or branch manager for physical documentation. |
| `ABANDONED` | Inactive Dropout | Borrower exited the journey and remained inactive for 7+ days. |
| `EXPIRED` | Session Timeout | Application exceeded the 72-hour journey validity TTL. |

### In-Flight Processing Statuses (`currentNextAction.type` / Active `status`)

While an application is actively being processed:

| Status Code | Current Phase | Next Step Required |
| :--- | :--- | :--- |
| `NEW` | Initiated | Application recorded, initial credit checks starting. |
| `POLL_FOR_OFFERS` | Evaluating Lenders | Automated credit assessment underway across banking partners. |
| `SELECT_OFFER` | Offers Ready | Approved credit offers are available for borrower selection. |
| `SELECT_GOLD_LOAN_BRANCH` | Branch Appointment | Gold Loan branch location and appointment selection required. |
| `SUBMIT_BANK_ACCOUNT` | Bank Details | Bank account number and IFSC required for disbursal penny drop. |
| `REDIRECT_TO_KYC` | Identity Verification | Digital KYC verification in progress via DigiLocker / Aadhaar. |
| `REDIRECT_TO_ENACH` | Repayment Mandate | Auto-debit eNACH mandate authorization in progress. |
| `REDIRECT_TO_ESIGN` | Agreement Execution | Digital loan agreement execution in progress via Aadhaar eSign. |
| `DISBURSED` | Disbursal Executed | Funds credited; pending final bank UTR reconciliation. |
