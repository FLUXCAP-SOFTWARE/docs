## Overview

The EASYCRED Partner API is a REST API that returns JSON. All requests require HMAC-SHA256 authentication.

## Environments & Base URLs

| Environment | Base URL | Purpose |
| :--- | :--- | :--- |
| **Production** | `https://api.easycred.co.in` | Live traffic and origination |
| **Development / UAT** | `https://dev.easycred.co.in` | Integration testing and verification |

### How to Import into Postman

<Steps>
  <Step title="Open Postman & Click Import">
    Launch Postman in your workspace and click the **Import** button in the top-left navigation bar.
  </Step>
  <Step title="Paste OpenAPI URL or Upload File">
    In the import dialog, select **Link** and paste:
    ```text
    https://api.easycred.co.in/api/v1/openapi.json
    ```
    *Alternatively, click the **Open OpenAPI Specification** button above, save the file as `openapi.json`, and drag & drop it into Postman.*
  </Step>
  <Step title="Confirm and Import">
    Click **Import**. Postman will automatically create the **EASYCRED LENDING APIs** collection with all pre-configured endpoints and parameter schemas.
  </Step>
</Steps>

## Required Authentication Headers

Every API call must include four signature headers in addition to standard request headers:

```http
x-api-key: ec_live_...
x-timestamp: 1749820800
x-nonce: <unique-uuid-v4>
x-signature: <computed-hmac-sha256-hex>
```

For Headless journey state and action calls, also pass the journey session token:
```http
X-Journey-Session: <jwt-from-initiate>
```

See the [Authentication Guide](/authentication) for request signing examples in Node.js, Python, and Java.

## Core Lifecycle Steps (`nextAction.type`)

Branch your application logic on `nextAction.category`:

| Category | Step Names |
| :--- | :--- |
| `POLL` | `POLL_FOR_OFFERS`, `POLL_FOR_KYC_LINK`, `POLL_KYC_STATUS`, `POLL_FOR_ESIGN_LINK`, `POLL_FOR_MANDATE_LINK`, `POLL_FOR_DISBURSAL`, `POLL_FOR_UPDATED_GOLD_LOAN_OFFER` |
| `COLLECT` | `SELECT_OFFER`, `SELECT_GOLD_LOAN_BRANCH`, `SUBMIT_BANK_DETAILS` |
| `REDIRECT` | `REDIRECT_TO_KYC`, `REDIRECT_TO_ESIGN`, `REDIRECT_TO_MANDATE` |
| `TERMINAL` | `COMPLETED`, `REJECTED`, `NO_OFFERS_AVAILABLE`, `OFFLINE_PROCESSING`, `ABANDONED`, `EXPIRED` |
