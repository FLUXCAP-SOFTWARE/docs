## Overview

The **Leads & Applications** section displays a searchable, filterable view of all loan applications submitted through your partner account. Statuses are mapped to standardized categories across all loan types.

---

## Status Reference

| Status | Stage Meaning | Next Step / Description |
| :--- | :--- | :--- |
| `NEW` | Lead captured | Application recorded in EASYCRED system. |
| `INITIATED` | Evaluation in progress | Credit parameters are being evaluated. |
| `OFFERS_RECEIVED` | Credit offers available | Review available loan options with the applicant. |
| `OFFER_SELECTED` | Offer confirmed | Applicant has confirmed their chosen loan option. |
| `KYC_DONE` | Identity verified | Borrower has completed identity verification. |
| `ENACH_DONE` | Auto-debit registered | Bank repayment mandate successfully established. |
| `ESIGN_DONE` | Agreement signed | Digital loan agreement executed by the applicant. |
| `SANCTIONED` | Loan disbursed ✓ | Funds credited to applicant's account. Commission entry generated. |
| `REJECTED` | Application declined ✗ | Did not meet credit policy criteria. |
| `ABANDONED` | Inactive | Borrower did not complete verification within the time limit. |

---

## Lifecycle Flow

```text
NEW
 └── INITIATED
      └── OFFERS_RECEIVED
           └── OFFER_SELECTED
                └── KYC_DONE
                     └── ENACH_DONE
                          └── ESIGN_DONE
                               └── SANCTIONED ✓
                    (terminal)
                    ├── REJECTED ✗
                    └── ABANDONED ✗
```

---

## Filtering & Details

Filter applications by:
- **Status:** View leads by any active or terminal status.
- **Date Range:** Filter by submission date window.
- **Product Type:** Personal, Pocket, Business, Gold, LAP, Home, Car, Education, or Working Capital.
- **Search:** Search by customer name, mobile number, or application ID.

Clicking **View** on any application displays the verified status timeline, sanctioned loan amount, disbursal date, and bank UTR reference code.
