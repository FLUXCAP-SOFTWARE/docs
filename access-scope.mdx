## Overview

EASYCRED uses permission scopes to secure real-time API endpoints. Your API key is assigned scopes when created in the [Partner Portal](https://partner.easycred.co.in).

Calls made without the required scope return `403 Forbidden`.

---

## Real-Time API Scopes

<ResponseField name="leads:create" type="Core Journey">
  Initiates real-time borrower loan journeys (both Hosted and Headless modes).

  **Endpoint:** `POST /v1/partner/journey/initiate`
</ResponseField>

<ResponseField name="offers:read" type="Core Journey">
  Retrieves approved loan offers and sanctioned credit terms from lending partners.

  **Endpoint:** `GET /v1/partner/journey/:id`
</ResponseField>

<ResponseField name="offers:select" type="Core Journey">
  Submits borrower offer selections and drives downstream verification steps (KYC, mandate, e-sign).

  **Endpoint:** `POST /v1/partner/journey/:id/action`
</ResponseField>

<ResponseField name="leads:status:read" type="Core Journey">
  Checks real-time application status, journey stage, and disbursement progression.

  **Endpoints:** `GET /v1/partner/journey/:id` and `GET /v1/partner/leads/:id/status`
</ResponseField>

<ResponseField name="products:read" type="Catalog">
  Fetches the list of enabled real-time loan products and their validation rules.

  **Endpoint:** `GET /v1/partner/products`
</ResponseField>

<ResponseField name="leads:read" type="Reporting">
  Lists historical loan applications submitted by your organization with pagination.

  **Endpoint:** `GET /v1/partner/leads`
</ResponseField>

<ResponseField name="webhooks:manage" type="Webhooks">
  Registers and manages webhook subscription endpoints for real-time lifecycle event callbacks.

  **Endpoint:** `POST /v1/partner/webhooks`
</ResponseField>

---

## Scope Errors

If an API call is made without the required scope, the server returns `403 Forbidden`:

```json
{
  "success": false,
  "error": "Missing required scope: leads:create"
}
```

<Tip>
  You can review your active API key scopes or request additional permissions directly in the **API & Credentials** section of the [Partner Portal](https://partner.easycred.co.in).
</Tip>
