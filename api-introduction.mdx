## Overview

The EASYCRED Partner API enables partner platforms to originate loan applications programmatically. You can either hand off borrowers to an EASYCRED hosted journey or drive every step natively within your own application.

### How to Import into Postman

<Steps>
  <Step title="Open Postman & Click Import">
    Launch Postman in your workspace and click the **Import** button in the top-left navigation bar.
  </Step>
  <Step title="Paste Collection URL or Upload File">
    In the import dialog, select **Link** and paste:
    ```text
    https://docs.easycred.co.in/api-reference/postman_collection.json
    ```
    *Alternatively, click the **Import Postman Collection** button above, save the file as `postman_collection.json`, and upload it into Postman.*
  </Step>
  <Step title="Configure Collection Variables & Run">
    Click **Import**. Open the imported **EASYCRED LENDING APIs** collection:
    1. Navigate to the collection **Variables** tab.
    2. Enter your `apiKey` and `signingSecret`.
    3. Select your `baseUrl` (`https://api.easycred.co.in` for Production or `https://dev.easycred.co.in` for Sandbox).
    
    *HMAC-SHA256 request signatures, timestamps, nonces, and session tokens are automatically computed on every request by the built-in pre-request script.*
  </Step>
</Steps>

## Integration Modes

Select your mode per request using the `channel` property:

<CardGroup cols={2}>
  <Card title="Hosted (API_HOSTED)" icon="globe">
    A ready-to-integrate lending journey that returns a `hostedUrl` for borrower redirection. Once redirected, EASYCRED manages the complete loan application journey, including credit assessment, lender offer discovery, offer selection till disbursement.

    **Best for:** Partners looking for the fastest integration and launch with minimal development effort.
  </Card>

  <Card title="Headless (API_HEADLESS)" icon="terminal">
    A fully white-labelled lending integration that gives you complete control over the borrower journey through REST APIs. Your backend retrieve application states, manage borrower inputs, submit offer selections, and handle third-party links at each stage of the journey

    **Best for:** Partners looking to build a fully customized, native lending experience within their existing mobile or web application.
  </Card>
</CardGroup>

See more details:  [Methods of API Usage](/methods-of-api-usage).

## Integration Workflow

1. **Obtain Credentials:** Receive your `API_KEY` and `SIGNING_SECRET` from us.
2. **Implement Request Signing:** Every request requires an HMAC-SHA256 signature generated using your `SIGNING_SECRET`(see [Authentication](/authentication)).
3. **Initiate Journey:** Submit customer details to `POST /v1/partner/journey/initiate`.
4. **Drive & Conclude:** Drive the journey as per selected channel, `HOSTED `or `HEADLESS`.
5. **Track Status:** Subscribe to webhooks or poll the status endpoint for real-time progress updates.
