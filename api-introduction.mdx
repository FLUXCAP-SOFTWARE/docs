## Overview

The EASYCRED Partner API enables partner platforms to originate loan applications programmatically. You can either hand off borrowers to an EASYCRED hosted journey or drive every step natively within your own application.

### How to Import into Postman

<Tip>
**Why does Postman sometimes create `api > v1 > partner...` folders?**

Postman defaults to **Folder organization: Paths**, which slices the raw URL path into subfolders. To see the organized 5-folder structure (**Product Access**, **Hosted Journey**, **Headless Journey**, **Tracking and Leads**, **Webhooks**):
- **Easiest:** Import the **Postman Collection URL** (`https://docs.easycred.co.in/api-reference/postman_collection.json`). It is pre-built with the 5 folders.
- **Or via OpenAPI:** In Postman's import dialog, click **Show advanced settings** and change **Folder organization** from **Paths** to **Tags**.
</Tip>

<Steps>
  <Step title="Open Postman & Click Import">
    Launch Postman and click the **Import** button in the top-left navigation bar.
  </Step>
  <Step title="Paste Link or Upload File">
    In the import dialog, select **Link** and paste either:
    - **Postman Collection (Recommended):**
      ```text
      https://docs.easycred.co.in/api-reference/postman_collection.json
      ```
    - **OpenAPI 3.1 Specification:**
      ```text
      https://docs.easycred.co.in/api-reference/openapi.json
      ```
      *(If importing via OpenAPI link, set **Folder organization** to **Tags** under advanced settings)*
  </Step>
  <Step title="Confirm and Import">
    Click **Import**. Postman will create the **EASYCRED LENDING APIs** collection with the 5 clean step-wise folders and complete request schemas.
  </Step>
</Steps>

## Integration Modes

Select your mode per request using the `channel` property:

<CardGroup cols={2}>
  <Card title="Hosted (API_HOSTED)" icon="globe">
    Returns a `hostedUrl`. Redirect the borrower or load it in a WebView. EASYCRED handles credit checks, offer display, KYC, e-NACH mandate, and e-Sign.

    **Best for:** Immediate launch with zero UI development.
  </Card>

  <Card title="Headless (API_HEADLESS)" icon="terminal">
    Returns a `journeySession` token. Your backend controls the borrower experience over REST, reading state, submitting user selections, and presenting third-party verification links.

    **Best for:** Native, fully branded mobile or web user experiences.
  </Card>
</CardGroup>

## Integration Workflow

1. **Obtain Credentials:** Receive your `apiKey` and `signingSecret` from the EASYCRED Partner Portal.
2. **Implement Request Signing:** Every request requires an HMAC-SHA256 signature generated using your `signingSecret` (see [Authentication](/authentication)).
3. **Initiate Journey:** Submit customer details to `POST /v1/partner/journey/initiate`.
4. **Drive & Conclude:** Poll state and post actions (Headless) or direct borrower to the hosted URL (Hosted).
5. **Track Status:** Subscribe to webhooks or poll the status endpoint for real-time progress updates.
