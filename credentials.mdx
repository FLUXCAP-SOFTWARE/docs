## Your API Credentials

At onboarding, EASYCRED issues you two values, store them securely in your secrets manager:

<CardGroup cols={2}>
  <Card title="`API_KEY`" horizontal>
    Sent in the `x-api-key` header on every request.
  </Card>

  <Card title="`SIGNING_SECRET`" horizontal>
    Used on your server to compute the HMAC-SHA256 signature.
  </Card>
</CardGroup>

## Security Guidelines

- **Environment Separation:** Always store keys in environment variables or cloud secret managers. Never commit keys to version control.
- **Compromise:** If credentials are unintentionally exposed, contact EASYCRED support immediately.
