## Your API Credentials

At onboarding, EASYCRED issues you two values. **Both are shown exactly once and cannot be retrieved later** — store them securely in your secrets manager:

<CardGroup cols={2}>
  <Card title="apiKey" icon="key">
    **Format:** `ec_live_…` (production) or `ec_test_…` (development)

    Sent in the `x-api-key` header on **every request**.
  </Card>

  <Card title="signingSecret" icon="shield-check">
    **Format:** 48-character hex string

    Used on your server to compute the HMAC-SHA256 signature. **Never sent over the wire.**
  </Card>
</CardGroup>

## Security Guidelines

- **Environment Separation:** Always store keys in environment variables or cloud secret managers. Never commit keys to version control.
- **Log Masking:** For debugging, log only the first 8 characters (e.g. `ec_test_fdf8d4a3...`). Never log the full key or the `signingSecret`.
- **Compromise:** If credentials are unintentionally exposed, rotate them immediately via the Partner Portal or contact EASYCRED support.
