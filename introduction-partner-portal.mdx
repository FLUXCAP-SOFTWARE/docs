## Overview

The EASYCRED Partner Platform enables Direct Selling Agents (DSAs) and API partners to originate customer loans, monitor application lifecycles, and track commission earnings.

---

## Two Integration Modes

<CardGroup cols={2}>
  <Card title="Partner Web Portal" icon="layout-dashboard" href="/dashboard">
    Ready-to-use web interface for lead submission, document upload, offer review, and payout tracking. Zero coding required.

  <Card title="Partner API" icon="terminal" href="/api-introduction">
