## Overview

A loan integration with EASYCRED consists of two core steps:
1. **Initiate the Journey:** Submit the applicant's profile and choose between Headless (`API_HEADLESS`) or Hosted (`API_HOSTED`) mode.
2. **Drive the Journey:** Poll state and handle required actions (Headless) or direct the user to the EASYCRED screen (Hosted).

## Step 1: Initiate a Loan Journey

Start an application by calling the initiate endpoint with customer data and your selected mode:

```http
POST {baseURL}/v1/partner/journey/initiate
```

**Required Scope:** `leads:create`  
**Headers:** `x-api-key`, `x-timestamp`, `x-nonce`, `x-signature`, `Content-Type: application/json`

### Request Body Parameters

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `channel` | string | Yes | `"API_HOSTED"` or `"API_HEADLESS"` |
| `productCode` | string | Yes | `"ONLINE_PERSONAL"`, `"ONLINE_SHORT_TERM"`, `"ONLINE_BUSINESS"`, or `"ONLINE_GOLD"` |
| `mobile` | string | Yes | 10-digit Indian mobile number (e.g. `"9876543210"`) |
| `customer` | object | Yes | Applicant profile information |
| `goldLoanDetails` | object | Conditional | Required only if `productCode` is `"ONLINE_GOLD"` |

### `customer` Object Schema

| Field | Type | Required | Validation / Notes |
| :--- | :--- | :--- | :--- |
| `firstName` | string | Yes | Applicant first name (must match PAN) |
| `lastName` | string | Yes | Applicant last name (must match PAN) |
| `pan` | string | Yes | Standard 10-character PAN format (`ABCDE1234F`) |
| `dob` | string | Yes | Date of birth in `YYYY-MM-DD` format (e.g. `1992-06-15`) |
| `gender` | string | Yes | `"MALE"`, `"FEMALE"`, or `"OTHER"` |
| `personalEmail` | string | Yes | Valid email address |
| `employmentType` | string | Yes | `"salaried"` or `"selfEmployed"` (Must be `"selfEmployed"` for Business Loans) |
| `monthlyIncome` / `annualIncome` | number | Yes | Provide `monthlyIncome` for personal/pocket loans; `annualIncome` for business loans |
| `pinCode` | string | Yes | 6-digit residential / operational PIN code |
| `city` | string | Yes | City name (e.g. `"Bengaluru"`) |
| `state` | string | Yes | State name (e.g. `"Karnataka"`) |
| `addressL1` | string | Yes | Residential / operational address line 1 |
| `addressL2` | string | No | Landmark or building name (optional) |
| `companyName` | string | Conditional | Required for `"ONLINE_BUSINESS"` (Registered trade or enterprise name) |
| `loanAmountRequired` | number | No | Desired initial loan amount (optional at initiation) |
| `termsAccepted` | boolean | Yes | Must be `true` |

> **Note on Loan Amount:** `loanAmount` is not mandatory at initiation. Borrowers are evaluated by lenders for their maximum eligible sanctioned credit limit. When selecting an offer (`SELECT_OFFER` in Headless or on the hosted UI), specifying the desired `loanAmount` within the approved range is mandatory.

### Example cURL — Initiate Journey

```bash
curl --request POST \
  --url https://dev.easycred.co.in/api/v1/partner/journey/initiate \
  --header 'Content-Type: application/json' \
  --header 'x-api-key: <api-key>' \
  --header 'x-nonce: <unique-uuid>' \
  --header 'x-signature: <computed-signature>' \
  --header 'x-timestamp: <unix-timestamp>' \
  --data '{
    "channel": "API_HOSTED",
    "productCode": "ONLINE_PERSONAL",
    "mobile": "9876543210",
    "customer": {
      "firstName": "Rahul",
      "lastName": "Sharma",
      "pan": "ABCDE1234F",
      "dob": "1992-06-15",
      "gender": "MALE",
      "employmentType": "salaried",
      "monthlyIncome": 65000,
      "personalEmail": "rahul.sharma@example.com",
      "pinCode": "560001",
      "city": "Bengaluru",
      "state": "Karnataka",
      "addressL1": "Flat 402, Green Glen Layout, Bellandur",
      "termsAccepted": true
    }
  }'
```

### `goldLoanDetails` Object (Gold Loans Only)

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `jewellaryList` | string[] | Yes | List of gold articles, e.g. `["Gold Bangle 22K", "Gold Chain 22K"]` |
| `grams` | string | Yes | Gross gold weight in grams as a string, e.g. `"35.5"` |

## Step 2 (Option A): Drive Headless Journeys

In Headless mode, your backend manages the borrower experience by polling state and submitting user actions.

### 1. Poll Journey State

```http
GET {baseURL}/v1/partner/journey/{journeyId}
```

**Headers:** Include `X-Journey-Session: <token>` in addition to your standard HMAC auth headers.

```json
{
  "success": true,
  "data": {
    "journeyId": "jrn_719b9dfa-741b-4c27-8a87-e0ab7f166520",
    "productCode": "PERSONAL_LOAN",
    "channel": "API_HEADLESS",
    "currentNextAction": {
      "type": "POLL_FOR_OFFERS",
      "category": "POLL",
      "pollIntervalSeconds": 10
    },
    "offers": [],
    "referralOffers": [],
    "outcome": null
  }
}
```

### 2. Action Categories

Branch your code according to `currentNextAction.category`:

| Category | Meaning | Required Action |
| :--- | :--- | :--- |
| `POLL` | EASYCRED is processing data in the background | Sleep for `pollIntervalSeconds` and query state again. |
| `COLLECT` | User selection or input is required | Prompt the user and submit an action payload to `POST /journey/{journeyId}/action`. |
| `REDIRECT` | External verification required (KYC, e-Sign, e-NACH) | Direct the applicant to `currentNextAction.url`. Upon return, notify EASYCRED via `redirect-returned`. |
| `TERMINAL` | Journey is concluded | Read `outcome` and cease polling. |

---

### 3. Submit User Actions (`COLLECT`)

When `category` is `COLLECT`, post the user's choice:

```http
POST {baseURL}/v1/partner/journey/{journeyId}/action
```

**Required Scope:** `offers:select`  
**Payload Format:** `{ "kind": "<ActionKind>", "payload": { ... } }`

#### Supported Action Kinds

- **Select Loan Offer (`SELECT_OFFER`):**
  ```json
  {
    "kind": "SELECT_OFFER",
    "payload": {
      "offerId": "01a10f78-403e-92bc-4890-50488113b866",
      "loanAmount": 500000
    }
  }
  ```
- **Select Gold Loan Branch (`SELECT_GOLD_LOAN_BRANCH`):**
  ```json
  {
    "kind": "SELECT_GOLD_LOAN_BRANCH",
    "payload": {
      "offerId": "01a10f78-403e-92bc-4890-50488113b866",
      "branchLocationId": "01a10f78-4092-5ee8-9f91-c3120d03c530"
    }
  }
  ```
- **Submit Bank Account (`SUBMIT_BANK_ACCOUNT`):**
  ```json
  {
    "kind": "SUBMIT_BANK_ACCOUNT",
    "payload": {
      "accHolderName": "Rahul Sharma",
      "acctype": "SAVING",
      "accNo": "123456789012",
      "ifscCode": "HDFC0000128"
    }
  }
  ```

---

### 4. Handle Verification Redirects (`REDIRECT`)

When `category` is `REDIRECT`, open `currentNextAction.url` in a browser or WebView for the borrower (for KYC verification, e-NACH mandate registration, or digital loan agreement signing).

Once the borrower completes the verification and returns to your application, inform EASYCRED:

```http
POST {baseURL}/v1/partner/journey/{journeyId}/redirect-returned
```

**Payload:**
```json
{ "kind": "KYC" }
```
*(Use `"KYC"`, `"MANDATE"`, or `"ESIGN"` depending on the completed step).*

Resume the `GET /journey/{journeyId}` poll loop immediately after signalling return.

---

### 5. Referral Offers (e.g. Apollo Finvest)

When credit evaluations are completed or when alternative options exist, EASYCRED returns secondary referral offers in the journey state inside `data.referralOffers[]`:

```json
{
  "success": true,
  "data": {
    "journeyId": "jrn_719b9dfa-741b-4c27-8a87-e0ab7f166520",
    "offers": [],
    "referralOffers": [
      {
        "lenderCode": "APOLLO_FINVEST",
        "name": "Apollo Finvest",
        "redirectUrl": "https://dev.easycred.co.in/r/af83c1b"
      }
    ]
  }
}
```

- **Hosted Journeys (`API_HOSTED`):** The EASYCRED hosted page automatically displays the Apollo Finvest referral card with a dedicated CTA that securely routes the applicant through `/r/<code>`.
- **Headless Journeys (`API_HEADLESS`):** EASYCRED does not send automated SMS messages in headless mode. Your application must inspect `data.referralOffers[]`, render the referral options in your custom UI, and provide the user with the corresponding `redirectUrl`.

## Step 2 (Option B): Hosted Journey Tracking

When using `API_HOSTED`, EASYCRED manages the entire borrower experience on hosted web screens. Your backend does not make step-by-step action or poll calls.

Track journey progress using either method:
1. **Webhooks (Recommended):** Configure an HTTPS endpoint via `POST /api/v1/partner/webhooks`. EASYCRED automatically sends signed real-time events (`journey.updated`, `journey.completed`, `journey.rejected`, `journey.failed`) carrying `data.journeyId` as the applicant progresses through hosted screens. See the [Webhooks Guide](/webhooks).
2. **List & Poll Applications:** Retrieve all applications originated by your account via `GET /api/v1/partner/leads?page=1&limit=20` to obtain `applicationId`, or check status via `GET /api/v1/partner/leads/{applicationId}/status`.

> **Note on `GET /journey/{journeyId}`:** The state endpoint `GET /journey/{journeyId}` is strictly an in-flight driver for **Headless** journeys and requires an `X-Journey-Session` token. It is neither required nor used in Hosted integrations.

## Journey Terminal Outcomes

When `category` is `TERMINAL`, the journey is complete. Read `data.outcome`:

| Outcome | Meaning |
| :--- | :--- |
| `COMPLETED` | Loan sanctioned and successfully disbursed. |
| `REJECTED` | The application could not be approved at this time. |
| `NO_OFFERS_AVAILABLE` | No lending offers matched the applicant's profile. |
| `OFFLINE_PROCESSING` | Routed to an EASYCRED field officer or branch team for physical fulfillment. |
| `ABANDONED` | Borrower did not complete verification within the allotted timeout. |
| `EXPIRED` | Application exceeded the 72-hour validity window. |
