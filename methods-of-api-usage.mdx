## Overview

EASYCRED offers two integration modes. Select the mode per application when calling the initiate endpoint using the `channel` parameter.

| Feature | Hosted (`API_HOSTED`) | Headless (`API_HEADLESS`) |
| :--- | :--- | :--- |
| **Response Payload** | `hostedUrl` | `journeySession` token |
| **User Interface** | EASYCRED provides the complete UI | You design and build the borrower UI |
| **Logic and Backend** | EASYCRED handles everything. | You build your complete backend |
| **Step Handling** | Managed by EASYCRED | Driven by your backend over REST APIs |
| **Offers** | Rendered automatically on the hosted screen | Delivered in the API to be handled by your backend. |
| **Best For** | Faster Go-to-Market and less development effort | Deep native app/web integration with full UI/UX ownership. |

## 1. Hosted Mode (`API_HOSTED`)

Start a journey and receive a single-use `hostedUrl`. Direct the customer to the URL in a browser or embed it within a secure WebView:

```http
POST /v1/partner/journey/initiate
```

## 2. Headless Mode (`API_HEADLESS`)

Your backend controls the applicant experience. Starting the journey returns a `journeySession` JWT token:

```http
POST /v1/partner/journey/initiate
```


### Headless Loop Architecture

1. **Poll State:** Call `GET /v1/partner/journey/{journeyId}` with `X-Journey-Session` to inspect `currentNextAction`.
2. **Handle Actions:**
   - **`POLL`:** Wait `pollIntervalSeconds` and read state again (`endpoint` is `null`).
   - **`COLLECT`:** Present choices to the borrower and post actions (e.g. `SELECT_OFFER`, `SELECT_GOLD_LOAN_BRANCH`, or `SUBMIT_BANK_ACCOUNT`) to `/api/v1/partner/journey/{journeyId}/action` (also available via `currentNextAction.endpoint`).
   - **`REDIRECT`:** Open verification URLs (KYC, e-Sign, e-NACH) for the borrower, then call `/api/v1/partner/journey/{journeyId}/redirect-returned` (also available via `currentNextAction.endpoint`) upon return.
   - **`TERMINAL`:** Read `data.outcome` and conclude the journey (`endpoint` is `null`). When `outcome === "COMPLETED"`, inspect `data.loanStatement` for the final disbursed amount, repayment schedule, and signed KFS PDF link.
3. **Handle Referral Offers:**
   When secondary lenders (such as Apollo Finvest) provide offers, they appear in `data.referralOffers[]`. Your app renders the offer card and opens the corresponding `redirectUrl`.
